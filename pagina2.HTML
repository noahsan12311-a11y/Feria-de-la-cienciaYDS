En esta sección se explica cómo fueron creados nuestros videojuegos utilizando Scratch y se presenta información sobre los tres integrantes responsables del proyecto.

> SOBRE_NUESTROS_JUEGOS

Para realizar nuestros proyectos utilizamos Scratch, una plataforma de programación visual que permite crear videojuegos, animaciones y aplicaciones interactivas mediante bloques.

Nuestro objetivo fue aprender conceptos básicos de programación mientras desarrollábamos diferentes proyectos interactivos.

Durante el proceso tuvimos que planificar las ideas, diseñar los personajes y escenarios, programar las acciones y realizar diferentes pruebas para comprobar que los juegos funcionaran correctamente.

SCRATCH_ENGINE // SISTEMA_DE_DESARROLLO

Los bloques de Scratch nos permitieron crear instrucciones mediante eventos, movimientos, variables, condiciones, ciclos, sonidos y diferentes elementos interactivos.

> PROCESO_DE_DESARROLLO

PROCESS_01 // IDEA

💡 Creación de la idea

Primero pensamos qué tipo de juego queríamos realizar, cuál sería su objetivo y qué tendría que hacer el jugador.

PROCESS_02 // DESIGN

🎨 Diseño

Creamos los personajes, escenarios, fondos y demás elementos visuales necesarios para nuestros proyectos.

PROCESS_03 // CODE

🧱 Programación

Utilizamos bloques de Scratch para programar movimientos, condiciones, puntuaciones, sonidos y acciones.

PROCESS_04 // TEST

🧪 Pruebas

Probamos los juegos varias veces para encontrar errores y comprobar que todas las funciones funcionaran.

PROCESS_05 // DEBUG

🔧 Corrección

Corregimos los problemas encontrados durante las pruebas y modificamos algunas partes del código.

PROCESS_06 // RELEASE

🚀 Resultado final

Después de completar las pruebas, terminamos nuestros juegos y los presentamos como parte del proyecto.
